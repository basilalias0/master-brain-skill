# tester help

Purpose: a ranked test report first, then the tests, with integrity rules (no deleted or skipped tests).
Use: `/master-brain test report <area>` or `test implement <area>`.
Languages: guard counts matched the real runners for JS/TS, Python, Go, Java, Rust, C#, Ruby, PHP; other frameworks are unchecked (frameworks.md).
Example: `/master-brain test implement lib/slug.js`
