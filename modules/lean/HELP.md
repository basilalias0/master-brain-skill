# lean help

Purpose: the shortest solution that works, with no code nobody asked for.
Use: `/master-brain lean [lite|full|ultra]`. It stays on until you say "stop lean" or "normal mode".
Levels: lite names the leaner option; full enforces the decision order; ultra deletes first.
Triggers: "lean", "lazy mode", "yagni", "simplest solution", "do less".
Example: `/master-brain lean ultra`, then "add caching to this API".
