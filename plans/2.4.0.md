## 7. Arena skill (Jakeschincariol/arena-skill, pinned)
- Pin checked 2026-10-19: commit `df07b8e518e10cdecd8cd7712d9958b6f396250e`, path `skills/arena`. sha256: SKILL.md `c06f9828566485d5bd6507150f454d6f37d49c2b02e5308b8f744a4a046bdf39`, bracket.py `f56ba7de9746c1aed77b5d6aee58a3c2ca07bd239896dbe7dba88654694c1fa2`, rubric.md `3296801e01035f3ad8dc2b57f0c47d84d296bbc716bf8b36bdb02b426c2735a5`, strategies.json `30517505dd84dba84e94c0a92ee7aaa48b5aee7817dd465fb04856b6b0d8ca40` → registry `fileSha256`.
- What it does: N competitors (default 100, `--quick` 16) get the same task file and different strategy cards. They meet in a single-elimination bracket: attack (≤ 7 attacks, FATAL/MAJOR/MINOR), defend and revise, then a rubric judge (correctness 30, completeness 25, robustness 20, specificity 15, clarity 10). A blind final check runs **only when there is a rejected answer** (`--baseline-file .arena/baseline.md`). State is in `.arena/<run>/arena.json` in the current directory and survives compaction. Results are never applied without the user's yes.
- Dependency: Python 3.8+ stdlib (no network or subprocess at this commit, per the input plan's read). master-brain stays Node-only; `decide` works without arena.
- Cost (`bracket.py plan` totals; +1 final check only with a rejected answer; × 55–160k per sub-agent): 4 → 19 / 20 ≈ 1.0–3.2M · **8 → 43 / 44 ≈ 2.4–7.0M** · 16 → 91 / 92 ≈ 5.0–14.7M · 100 → 595 / 596 ≈ 33–95M.
- Fit: one model family, so this is best-of-N with a verifier, not mixed-model debate. Plain debate rarely beats majority vote at equal compute (the input plan cites arXiv 2310.01798, 2311.17371, 2509.05396; not re-read). Hence rare use and small N.
- "Sub-agents write only inside `.arena/`" is an instruction, not enforced; §8.3 item 11 checks it.
